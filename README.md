# MadoriApp

間取りを提案するアプリ

一軒家の間取りを3案生成するWebアプリ。アイデア出し用で、建築基準法・構造の厳密さは対象外。

## 概要

- 入力: 延床面積（20〜40坪）、階数（平屋/2階建て）、個室数（2〜5）、駐車場、庭、こだわり8種（対面キッチン、土間、書斎、ウォークインクローゼット、パントリー、吹き抜け、和室、ランドリー室）
- 出力: 条件に沿った間取り3案をSVG図面で並べて比較。各案に名前・特徴タグ・実測延床・スコアを表示し、拡大表示と再生成ができる
- 無理な条件（平屋+吹き抜け、20坪+個室5など）は、理由と代替案を表示する

## 技術メモ

- 生成: 455mmグリッド上のスライシング木（H/V分割+部屋葉）。配分はclamp付きwater-filling+最大剰余法
- パイプライン: 候補を大量生成 → ドア/窓を隣接グラフから自動生成 → ハード制約で検証・棄却（動線の到達可能性、居室の採光、階段の両階一致、吹抜の整合）→ スコアリング → 多様性で3案を選抜
- テンプレートは部屋単位ではなくクラスタ単位（玄関+土間、キッチン+パントリー、主寝室+WICなど）
- seed付き乱数で再現可能。入力+seedはURLハッシュに保存される
- v1スコープ: アーキタイプ3〜4個、南北道路のみ、矩形外形のみ

## 現在の形態

Museのスペース（静的ページ）として作成した単一HTMLファイル（`index.html`）が正本。
開けばそのまま動く（要Webサーバー配信。`file://` では一部機能が制限される場合がある）。

## 今後

- React 19 + TypeScript + Vite + Tailwind CSS v4 構成の実プロジェクトへ移植し、本物のWebアプリとして育てる
- 生成ロジックの中核はフレームワーク非依存の純関数モジュールとして分離する設計
